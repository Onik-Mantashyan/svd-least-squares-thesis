## Սինգուլյար վերլուծությունը փոքրագույն քառակուսիների մեթոդի գծային խնդրում

Ավարտական աշխատանքի տեսական նյութերն ու փաստաթղթավորումը։

### Կառուցվածք
- `latex/main.tex` — աշխատանքի LaTeX կոդը (XeLaTeX)
- `latex/main.pdf` — կոմպիլյացված PDF տարբերակը

### Ներառված բաժինները (ընթացիկ փուլ)
- Նախաբան
- Գծային և բազմանդամային ապրոքսիմացիա (փոքրագույն քառակուսիների մեթոդ)
- Մատրիցային ֆակտորիզացիայի տեսակները
- `LU` վերլուծություն
- `Uᵀ·U` (Խոլեսկի) և `Uᵀ·D·U` վերլուծություններ
- Հաուսհոլդերի ձևափոխություն և `QR` վերլուծություն
